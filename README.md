# 🏦 2. Bank Loan Analytics & Risk Performance Dashboard

### 🛠️ Tech Stack

Microsoft Excel | MySQL | Microsoft Power BI | Tableau

### 🎯 Project Overview

Analyzed **65K+ bank loan records** to understand loan distribution, repayment behavior, branch and product performance, and overall portfolio risk.

The analysis supports better lending decisions, improved risk management, and increased profitability.

### 🔍 Key Analysis & Business Findings

- 📅 **Lending Trends:** Created Year, Month, and Quarter dimensions to analyze lending activity over time.
- 💰 **Financial Performance:** Reported 733M+ in loans issued, 808M+ collected, and 155M+ in interest earned.
- ⚠️ **Credit Risk:** Identified an approximately 2% default rate and 7,106 delinquent clients.
- 🏦 **Branch Performance:** Compared branches to identify the strongest revenue contributors.
- 🗺️ **Geographic Distribution:** Analyzed lending activity across states, including Punjab, Uttar Pradesh, and Bihar.
- 👥 **Borrower Demographics:** Identified customers aged 26–35 as the largest borrower group.
- 📊 **Customer Grades:** Examined loan exposure across customer grades, with the highest exposure concentrated in Grades B and C.
- 🛍️ **Loan Product Analysis:** Identified XLG loans as generating 600M+ in revenue.
- ⏳ **Loan Tenure:** Found 36-month loans to be the most preferred tenure.
